# 工程清理记录

这份记录按开发轮次保存当时的修改和测试。第一轮解决关闭编辑器时资源释放的顺序，第二轮让模型移动后仍能识别，第三轮集中检查 3D 渲染。当前实现见[引擎架构](latex/main.tex)，后续 OpenGL 与 Vulkan 的工作见[接入方案](latex/rhi/main.tex)。

## 第三轮的 3D 渲染修正

- 以早期 2D 写法为参照整理资源、渲染和后端的职责注释。类说明使用块注释，复杂过程按功能分段。Shader 先解释效果与计算过程，再解释变量；绑定信息放在对应声明旁。未改写用户本人编写的 Renderer2D。
- 修复深度预传递漏用颜色贴图透明度的问题，与主绘制共用材质上传；透明度按颜色因子、颜色贴图和独立透明度图相乘。
- 金属度与粗糙度图的尺寸不一致时拒绝合并，释放临时数据，避免按错误尺寸读取。删除凭 glass / mirror 名称和默认透明颜色猜测材质的分支，普通 OBJ 不再丢失网格，导入器不再据名称改金属度或删除法线贴图。半透明混合仍未实现。
- Shader 缓存按源码内容、阶段和当前编译配置区分，修复同名文件冲突和保留时间戳时读旧缓存；移除未使用的缓存写入及泄漏的临时程序对象。当前编译目标仍为 OpenGL。
- 修复顶点数组析构未释放 GPU 对象；ShaderLibrary 查询使用 `at`，不再反向断言或插入不存在的项。
- 删除确认无调用的 MaterialLibrary、材质旧兼容接口、ExecuteDraw、无用状态和参数。绘制入口统一有效网格和材质，删去队列处理中的重复兜底。
- 当前架构文档与 RHI / Vulkan 计划分别维护。计划包含分层图、资源寿命、帧同步、Shader、GUI 与分阶段验收；参考图标明 Khronos 来源和许可。没有新增 RHI 或 Vulkan 后端代码。
- 排错原因与旧问题见 `docs/latex/debugging/main.tex`，性能采样与取舍见 `docs/latex/decisions/main.tex`。没有做新旧版本的性能基准比较，不声称本轮获得了帧率提升。

## 模型、阴影与环境光

普通模型和实例化模型现在使用同一份网格着色器。每个物体的变换、材质数值和实体编号可从实例数据读取，后面的光照公式共用。对同一个像素输入红色间接光，单独画和合批得到相同颜色，拾取仍能区分左右物体。

主相机之外的模型继续参与阴影与反射阴影图计算。预写深度、主画面、阴影和反射阴影图使用相同的透明裁剪条件。导入模型时保留文件明确指定的黑色、透明度、零金属度和零粗糙度。混合透明物体仍待实现。

OpenGL 明确区分旧 GLSL 示例的具名 uniform 和现代 GPU 程序。后者按同一数据位置命名跨阶段参数块，解决了 RSM 程序把模型和材质错配的链接错误。删除 56 个旧命名的着色器编译产物，新缓存由本机生成。保存的原始 RenderDoc 帧覆盖了深度预写和主绘制，阴影、实例化和环境光的证据另见专项测试。

IBL 预计算隔离绘制状态并释放全屏网格。天空盒只写颜色，编辑器拾取和屏幕法线得以保留。纹理上传遵循解码器的紧密行布局，单通道到四通道的输入都经过了 GPU 读回。2D 混合、后处理及深度预览在编辑、运行两条路径分别验证。

本轮验证使用 RedflagForge Debug / x64。八组回归全部通过。另逐一链接了编辑器目录中的 15 个着色器文件，网格着色器的实例化版本通过实际绘制验证。

## 红墙与白地板的反射光

固定相机，在同一白地板上比较开启与关闭 RSM 的线性 HDR 差值。原方向光只照亮绿墙，转向红墙后红色分量才出现。修复投影通量中重复的入射余弦，均匀圆盘采样按世界投影面积换算，两端的漫反射都排除纯金属。样本数变化后仍覆盖整个指定半径。光照、采样设置或视口历史改变时重新积累，上一帧裁剪范围外的点使用当前帧。默认间接光倍率为 1。

- 斜照红墙、相同倍率 5、同一地板像素的红色增量由 0.07715 变为 0.48218。工程最终画面采用倍率 1，测得 0.09644。
- 复现用场景、开关对照、实际回放以及灯光覆盖限制见 `docs/latex/scenes/main.tex`。数学推导与短代码见 `docs/latex/math/main.tex`，测试输出节选在 `output/validation/rsm-regression.txt`。

## 第二轮的模型登记与后处理

- 按 Hazel 的 ShaderLibrary 风格命名 AssetLibrary，头文件声明接口，cpp 实现登记、扫描和查询。
- AssetID 写入模型旁的 `.rfmeta`；ModelRendererComponent 保存 ModelID，场景支持旧 FilePath 迁移。
- AssetManager 使用 ID 缓存。编辑器登记资源，渲染阶段只按 ID 加载，不再逐帧登记路径。
- 在 assets 内移动模型和元数据后，重新打开场景可恢复引用。assets 外的已保存路径只在元数据 ID 一致时恢复，跨盘路径使用 proximate 保留绝对路径。
- 模型卸载同时清空组件 ID、路径和覆盖材质，避免下一帧重新加载。ContentBrowser 隐藏元数据。
- Bloom 和 Tonemap 拆为 PostProcess 实例，独立持有设置、目标、Shader、UBO 和绘制资源。SceneRenderer 其余阶段仍为静态。
- 删除上一轮临时保留的 Core/AssetManager.h 兼容壳；项目已统一使用 Assets 路径。
- 架构文档改为 docs/latex/main.tex + TikZ，旧 Python 生成器移除。输出为 output/pdf/Redflag-Architecture-LaTeX.pdf。
- 资产测试覆盖 ID 持久化、移动、坏元数据、重复 ID、类型校验及缓存所有权。GPU 测试覆盖两个后处理实例的不同曝光、交替渲染、Resize、Bloom 开关和销毁。
