# Fox

本目录中的 `Fox.glb` 来自 [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox)。模型保留原始比例，示例在场景里统一缩放。文件内含 Survey、Walk 和 Run 三个动作。

PixelMannen 创作狐狸模型（[CC0](https://creativecommons.org/publicdomain/zero/1.0/)）。tomkranis 制作骨架和动画（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。AsoboStudio 和 scurest 完成 glTF 转换（CC BY 4.0）。[作者与许可原文](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Fox/README.md)。

本项目原样分发 [glTF 二进制文件](https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Fox/glTF-Binary/Fox.glb)，SHA-256 为 `d97044e701822bac5a62696459b27d7b375aada5de8574ed4362edbba94771f7`。
