# 停步、离开护栏与移动射击

两段录像来自实际 Vulkan 游戏窗口。约第 2 秒松开前进键，可以观察蓝灰色维修员的腰和双脚。第 3 秒起按住后退键，直到西侧护栏。约第 7.5 秒重新按前进键，观察角色能否走开。[旧版录像](before.mp4) · [新版录像](after.mp4)

| 同一操作下测量的位移 | 旧版 | 新版 |
| --- | ---: | ---: |
| 从走路换到待机时，骨盆相对角色向后移动 | 23.66 厘米 | 0.59 厘米 |
| 计入侧向偏移后的骨盆水平位移 | 28.00 厘米 | 0.83 厘米 |
| 到护栏前按住后退键走过的距离 | 6.25 米 | 6.26 米 |
| 贴到护栏后，再按前进键走开的距离 | 0 米 | 1.33 米 |

新版第 23 帧触发臂炮脉冲。第 23 至 26 帧，脚仍在播放持炮走路，脊柱以上同时播放开火动作。这四帧里角色走了 0.66 米。片末站稳后又开了一炮，可以看到手臂收回待机的位置。[四帧连拍](moving-fire.jpg) · [逐帧世界坐标、剪辑和上身权重](after.csv)

旧版直接运行当时的候选包。新版从同一关卡打入待测的 Release 引擎、正式角色模型、蒙太奇和游戏脚本，输出均为 1280 × 720。游戏每一帧的间隔略有差异，读数按本次实际收到按键和换动作的帧计算。压缩包、程序、场景和脚本的 SHA-256 及采样帧号保存在测量文件里。[测量记录](result.json) · [旧版原始轨迹](before.csv) · [检查脚本](../../../tests/review_walk_stop.py)
