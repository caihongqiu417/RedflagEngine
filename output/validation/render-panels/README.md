# 渲染设置与四个效果窗口

打开维修站，编辑器右下角可以并排放置「渲染设置」「阴影」「AO」「体积雾」和「抗锯齿（AA）」。本次从顶部的「窗口 → 阴影」切到阴影页，又从场景视口的「实时效果 → 体积雾」切到雾的参数。实时效果弹层同时保留了直接光、间接光和反射等快捷控件。[五个同级标签](windows.png) · [窗口菜单](window-menu.png) · [场景视口入口](viewport-menu.png)

复测使用维修站的临时副本，预览宽度设为 640 像素。先选阴影标签，点击「级联层数」滑条设为 2。再依次打开另外三个标签，按住 Ctrl 点击对应滑条，输入表中的数值并按 Enter。保留 GTAO、体积雾和 TAA 的开启状态。按 Ctrl+S 保存，退出 Forge，在新进程里重新打开这份场景。下表的第二列来自修改前的面板，最后一列已逐项对照重开的面板及场景旁保存的 YAML。[抗锯齿页实拍](anti-aliasing.png) · [重开的四个窗口](reopened.jpg) · [保存的设置文件](saved.render.yaml)

| 窗口与参数 | 修改前 | 修改并重开后 |
| --- | ---: | ---: |
| 阴影 · 级联层数 | 0 | 2 |
| AO · 遮蔽半径 | 0.650 | 0.850 |
| 体积雾 · 雾密度 | 0.009 | 0.018 |
| 抗锯齿 · TAA 历史权重 | 0.900 | 0.770 |

TAA 的历史权重和 SSAA 2×2 开关在同一页。此处用四个容易区分的值核对保存与读取，货场的正式场景仍保留作者选定的参数。[构建指纹与实际读数](result.json)
