# 瓦特怎样处理一条没核实的消息

测试房间里只有瓦特、一盏灯和一块棕色墙面。玩家在前方 4 米处做了标记，说「前面似乎有一箱补给，也可能只是个空架子」。没有创建补给箱实体。Qwen3-VL-2B-Instruct 收到玩家要求后，先选择了转告消息，原话里的「似乎」「可能」均保留。随后玩家请它走近再看，瓦特沿地面走了 3 米，到离标记 1 米处停下，用自己的相机重新拍照。它回答只能辨认出方形物体，无法判断具体是什么。库存从头到尾为空。又发起一次观察后取消，延迟返回的上一条回复没有改变记忆，也没有启动动作。[模型选择、位移和回执](search.tsv)

第一次运行时，「去我标记的地方，走近一点重新观察」被模型理解成站在原地看。查看选择记录可以发现，它直接选了原地拍照，移动系统根本没收到目标。改动集中在瓦特的角色设定和两个候选的说明里，把「原地看」与「走到标记再看」说具体。同一句玩家指令再次运行时才出现了上述 3 米位移。这是一次复测，两条指令不足以代表其他说法的成功率。[第一次的实测记录](first-choice.tsv) · [角色配置](../../../RedflagForge/assets/ai/watt.npc.yaml)

另外拍了同一面白墙和红色立方体。模型认出旧照片中相同的特写后，分别在等待回答期间放入一块挡板、移走立方体。两张照片均进入角色记忆。挡板能挡住伸手，已删除的物体无法放进背包。再拍空墙时，模型有「没找到」和「不确定」两个选项。每张照片的拍摄位置、问题、实际选择和是否保存都在原始表里。[旧照片，随后加入挡板](06.png) · [旧照片，随后移走物体](04.png) · [移走后的实景](05.png) · [实际答复](observations.tsv)
