# 从西边出生点到东侧维修棚

这两局都从发行包的西侧出生点开始。镜头保持开局方向，玩家用 WASD 走到同一台应急发电机。两局都没有开炮，也没有指挥瓦特。可见的生命变化、动作时刻和位置取自运行中的游戏。录像保留了每次采集窗口画面之间的实际时间。

| 路线 | 走过的距离 | 从第一条移动指令到棚前 | 首次追赶 | 玩家到达时的生命 |
| --- | ---: | ---: | ---: | ---: |
| 中央通道 | 18.12 米 | 6.96 秒 | 2.61 秒 | 88/100 |
| 北侧货柜后方 | 40.02 米 | 13.80 秒 | 7.94 秒 | 100/100 |

**中央通道。** 面朝东侧维修棚按 W。巡检机在第 3.69 秒开始蓄能，玩家在通道内稍停，第 4.57 秒巡检机放电，玩家损失 12 点生命。继续向东，玩家停在离发电机 0.98 米的位置。两名角色靠近货柜时，跟随镜头一度被玩家的手臂挡住，录像保留了这段实际画面。[完整录像](central/route.mp4) · [放电时的游戏窗口](central/discharge.png) · [逐帧位置与巡检机动作](central/route.json)

**北侧货柜。** 先按 S 退到西货柜与围栏之间，按 A 沿货柜背面走到北道，按 W 东行，最后按 D 走回维修棚。巡检机在路上追了 3.25 秒，随后搜索 2.53 秒，等玩家到棚前时已经恢复巡逻。玩家停在离发电机 0.90 米的位置，画面上已经出现维修提示。[完整录像](north/route.mp4) · [北侧入口](north/cover.png) · [维修棚门前](north/generator.png) · [逐帧位置与巡检机动作](north/route.json)

两局使用 `Redflag-Watt-Yard-05.zip`，SHA-256 为 `17deb33c30d164ea0121e9ef9395c3d3a62cb9a819a9cee8e433295f26ed9586`。独立游戏窗口以 1280 × 720 渲染。中央录像采得 47 张画面，北侧 90 张。每条路线只走了一次。该包记录巡检机的行为和玩家实际扣血，缺少逐帧的目标编号，北侧途中只能确认发生过追赶，无法据此辨认它当时看到哪位队员。

在仓库根目录运行以下命令，给第二个参数选一个新目录。脚本直接解压游戏包、打开正常第三人称窗口并逐帧读取玩家的位置。录像、截图与事件记录在每条路线结束后写入目录。

```powershell
python tests/capture_station_routes.py tmp/Redflag-Watt-Yard-05.zip tmp/watt-routes-repeat
```
