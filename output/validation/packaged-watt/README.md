# 潮汐维修站实机画面

`yard-original.png` 直接截取自 Windows 上的 Redflag Game 客户区，原图为 1920 × 1080。`yard-preview.png` 是把同一帧等比例缩小到 1050 × 591 的预览。两图的人物、布景、阴影和 HUD 都由 Vulkan 游戏程序在运行时绘制。这一帧使用的程序 SHA-256 为 `29390546617faa6f18a0a69432af8b473e2d09feb18234f6f4571653fa58ec9c`。

通讯和递药画面来自另一次干净解压的试玩，用该包的启动脚本打开同一关卡。逐一核对了清单中 590 个文件的 SHA-256。开始时玩家与瓦特各有一份医疗包。测试通过实际窗口输入“请把你背包里的一份医疗包送到我手上。”，动作播放时库存完成交换，玩家有两份，瓦特的背包空了，随后瓦特恢复跟随。这次两人原本就靠在一起，模型实际选了留药。远处主动送药需要另测。[游戏窗口](radio.png) · [递药后](transfer.png) · [状态](transfer.json) · [逐帧事件](transfer-frames.jsonl)
