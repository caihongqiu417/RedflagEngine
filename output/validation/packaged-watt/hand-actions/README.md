玩家是灰蓝色机器人，瓦特是赭黄色机器人。录像长 59 秒。前五章由玩家操作，后五章让瓦特做相同的事。左上角的手部近景裁自同时刻的游戏窗口。看拾取时，可以跟着地面医疗包上的红十字看它到了谁手里；看修理时，留意发电机黄色面板上的拨杆。扶人这一章从队友倒地开始，保留他重新站起来的一段。播放器支持章节，也可以按[时间表](after/chapters.json)跳转。

以下帧号分别从各章开局计算。每章都是一次全新的游戏。手与目标的距离在游戏真正批准库存、生命或机器状态改变的那一刻记录，单位为厘米。递药有两行判定，送出者和接收者各自的握持点都须距交接点不超过 4 厘米；手套外壳留有厚度。拾取时对准药包模型内标出的握持点，另用整个 GLB 的三角形独立量到最近表面的距离。修理量手指到开关，扶人量手指到队友手腕，自疗量手持药包到胸前预设的位置。[逐帧测量与原始交互事件](after/measurements.json)

## 输入与机位

玩家走到近处后按 E 拿药包，按 G 给瓦特递药，按 H 使用自己背包里的药，修理和救援需要按住 E。瓦特的拾取、递药、修理与自疗由玩家从 T 通讯栏发出完整中文要求，本机实际运行的 Qwen3-VL-2B-Instruct 选择行动；玩家倒地时瓦特自行赶来。左上角的特写来自当时的游戏窗口，不会补出摄像机看不见的手指。

十章录像均在发行 ZIP 解压后的维修站中运行。为了从侧面同时看到双手、道具和伤者，在临时关卡副本里固定观察相机，向玩家或瓦特前方移动目标；自疗开局生命设为 40，救援开局伤者设为 0。用于瞄准的第三人称相机仍由正常游戏逻辑更新。为让待拍者保留拍摄位置，瓦特的日常行为设为等待，其余游戏脚本、模型及材质沿用发行包。每章的临时摆位保存在测量文件的 `scene`，另附一段 6.7 秒原关卡实录，沿用发行包的场景、出生点和默认相机；瓦特在第 53 帧把药递给玩家。

窗口按 1920 × 1080 开启，场景内部以 1280 × 720 绘制。影片按游戏时间播放，截取到的相同帧就保持在屏幕上。桌面取图与引擎记录状态的时机可能相差一个游戏帧，持续接触的中段最容易看见手指位置。近景中手指可能被手套挡住，数字给出两个实际坐标之间的距离。另外，扶人对准腕部，起身动作由另一条动画播放，过程中的碰触没有连续的手指抓握模拟。

音轨保留游戏实际提交给播放设备的瓦特台词。每句按同一局的设备时间记录对齐，在停止或完成时截断到实际播放的样本数。玩家的操作片段保留安静，未添加解说、配乐或后配对话。每章语音 SHA-256 可同发行包中的 `assets/audio/watt` 对照。近景录像与声音均可核对。[旧发行包回放](before/README.md) · [长帧的定位与实测](performance/README.md)

## 复测

发行 ZIP SHA-256 为 `214f172252edcac651d1ba9d9aa9416cf017796b15451990380ae31c77af2073`。原生程序 SHA-256 为 `85627901da8b108eacb20cfaf05128493834c6caae2d9175f00793dd6f9911eb`。在仓库根目录用 Windows PowerShell 运行下面两行。拍摄需要 pywin32、Pillow 和 PyYAML，本机真实 NPC 决策服务应已连接。测量与剪辑另外需要 NumPy、SciPy、trimesh 和 FFmpeg。选择一个新的拍摄目录，每个用例都会留下按键、模型选择和未剪辑的逐帧文件。

```powershell
python tests/capture_station_hands.py output/releases/Redflag-Watt-Station-Win64.zip tmp/my-station-takes
python tests/review_station_hands.py output/releases/Redflag-Watt-Station-Win64.zip tmp/my-station-takes tmp/my-station-film --verify --film
```

如要保留原房间与默认镜头，可在拍摄命令最后添加 `--original --cases watt-give`，输出到另一目录。严格复核会检查两方各五项、动作前后库存和生命、实际接触距离、被扶一方重新站立、操作者恢复移动与语音文件来源。每项发生于游戏自身的更新循环，捕获脚本只能发送玩家通用的键鼠操作。
