# 潮汐维修站 · 货场试玩

这一局从发行包的出生点开始。玩家用通讯栏让瓦特维修，自己先到西侧闸口。第 140 帧，瓦特的手够到发电机开关，机器恢复供电。那时玩家已经在闸口，游戏继续等待瓦特。第 216 帧，两人到齐后才完成任务，瓦特还有 56 点生命。[任务经过](mission/mission.json) · [撤离画面](mission/extracted.png)

重新开局后，玩家靠近巡检机，第 435 帧倒地。第 703 帧两人都失去行动能力。按 R 后，第 713 帧两人回到出生状态，各有 100 点生命和一份药，发电机也重新停机。[失败画面](mission/defeat.png) · [重新开局](mission/recovered.png) · [逐帧记录](mission/frames.jsonl)

想看关卡怎么走，可以先看第三人称录像。中央车道直通维修棚，中间有一段带电地面；北边绕过货柜也能到达同一台发电机。两段都保留了原关卡、出生点和正常跟随镜头。想看手是否碰到物件，可以打开固定侧面机位的十章录像，再对照原关卡的一次递药。[中央车道](../../station-encounter/yard-07/central/route.mp4) · [北侧货道](../../station-encounter/yard-07/north/route.mp4) · [侧面实机与接触测量](../hand-actions/README.md) · [原关卡递药](../hand-actions/original/actions.mp4)

本次从新目录解压 Win64 发行包，校验 636 个文件，通过游戏窗口输入中文和按键。整局用 RTX 5070 Ti Laptop GPU 运行，窗口为 1920 × 1080，使用包里的 720p 启动项。记录的 722 帧中，帧耗时中位数为 91.28 毫秒，第 95 百分位为 143.67 毫秒。这一局仍能感到卡顿。发行 ZIP 和可执行文件的 SHA-256 都在结果文件中。[运行环境和测量结果](mission/result.json)
