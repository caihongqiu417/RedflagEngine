# Operator 的支撑点

角色的原点在脚底。把玩家模型的原点放到水平面上，按每秒 120 次播放发行包的 GLB，把每个顶点随骨骼运动后的位置算出来，就能量出动画本身留了多大的缝。下表的负数代表表面略微穿过模型地面。瓦特用同一个模型，场景中的等比缩放为 0.96。这里的测量适合检查导入的动作，实际运行还会受到角色位置、碰撞地面和脚部调整的影响。

| 动作 | 全身最低点的范围 | 全程最高处 |
| --- | ---: | ---: |
| 站立待机 | −1.95 至 −1.31 毫米 | 1.929 米 |
| 原地蹲伏 | 约 0 至 0.15 毫米 | 1.297 米 |
| 蹲着走 | −0.4 至 3.3 毫米 | 1.331 米 |
| 倒下 | −3.0 至 7.9 毫米 | 1.661 米 |
| 站起 | −3.0 至 7.0 毫米 | 1.661 米 |

倒地结束时，身体最先着地的是背后的装甲包。胸甲下缘距地 1.44 厘米，髋部下缘 8.48 厘米，靴底 4.24 厘米。横躺着时，靴底与地面之间留出的这点空隙符合模型形状。沿身体长轴从头到靴尖量得 1.834 米，背部朝地时的全身厚度为 0.658 米。这些量对应卧姿碰撞体的总长和直径。双手张开时比躯干更宽，手和物件的接触仍用各自的握持点检查。

复测时在仓库根目录运行下面的命令。脚本按每个顶点保存的四个骨骼权重计算位置，固定负责水平位移的根骨，和游戏播放步态时一致。报告还保留了模型 SHA-256、各动作采样数和倒地末帧的网格范围。[原始数字](model.json) · [测量代码](../../../../tests/check_station_ground_pose.py)

```powershell
tmp/retarget-env/Scripts/python tests/check_station_ground_pose.py output/releases/Watt-Station-Win64/assets/game/station/crew/Operator.glb tmp/ground-pose.json
```
