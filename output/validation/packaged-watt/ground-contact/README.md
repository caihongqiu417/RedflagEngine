# 蹲伏和倒地时，角色离地有多高

蹲伏时看蓝色玩家承重的那只靴子。旧版里，靴底同砂石之间隔着 10.50 厘米，蹲低身体以后缝隙尤其明显。倒地时换一个观察位置更容易看清。这个机器人背着一个突出的装甲包，仰面躺下后是背包先碰地，靴子仍可以略微翘起。新版里，背包下缘接触砂石，胸甲下缘距地约 1.44 厘米。[侧面实机对照，12.54 秒](compare.mp4) · [四组静帧](compare.jpg) · [正常游戏镜头下的蹲姿](original.jpg)

## 出生高度与受击后的下落

旧场景把角色原点放在世界高度 0.08 米，出生点周围能看见的砂石在 −0.025 米。蹲姿动画本身已经让一只靴子的最低点落到模型原点，游戏却保留了这 10.5 厘米高差。修正关卡的地面碰撞和出生高度后，同一动作会贴到脚下看到的砂石。[维修站场景](../../../../RedflagForge/assets/scenes/Watt-Station.redflag)

跳起后受击还有另一处问题。旧版进入倒地分支后停止了移动更新，倒下的动画播完，角色仍悬在受击时的位置。新版受击后继续向下移动，落地再停。最终发行包的这一局在第 59 帧受击，角色原点高出地面约 0.96 米。第 63 帧原点到达地面，经过了约 0.31 秒。两次运行的受击高度随实际输入时机略有差别。旧版从受击到这次录像结束都悬在原处。[跳起后倒地的侧面实拍](airborne.jpg) · [新版逐帧位置](after/jump/poses.json) · [旧版逐帧位置](before/jump/poses.json)

## 实拍与复测

每个版本都从发行 ZIP 独立解压。正常视角保留关卡、出生点与第三人称相机，依次站立、按 Ctrl 蹲伏、向前蹲走、松开 Ctrl 起身。侧拍临时增加固定相机，把原有电缆移到出生点附近，调整电缆放电的时间、范围和伤害。空中受击这一局还提高了电缆的检测高度。瓦特在拍摄时等待，方便保留倒地后的姿势。两位角色和地面的摆设取自各自发行包。录像由真实 Vulkan 游戏窗口拍摄，按游戏时间回放，未加声音。[原关卡运行数据](after/original/poses.json) · [瓦特运行数据](after/watt/poses.json)

为量到画出来的表面，拍摄脚本在临时模型副本里给每个实际参与蒙皮的关节加了三个不可见的轴端点。试玩记录写出关节原点和三个端点的世界坐标，据此能还原每帧关节变换，再按原模型的权重求出顶点位置。这些点不携带网格，也不修改动画轨、已有顶点或权重。复查脚本再用脚下的 X、Z 坐标与砂石、路面和车辙的三角形求交，取最上层表面比较高度。最后逐帧检查站稳的蹲姿和倒地定格。实机与数值覆盖的是维修站出生区这一段地面。[拍摄代码](../../../../tests/capture_station_ground.py) · [高度和录像复核](../../../../tests/review_station_ground.py)

仓库根目录下运行下面的命令。其中 $zip 指向被测版本，$run 是新的临时拍摄目录。对两个版本各拍一次，将两套目录和 ZIP 依次交给复核脚本。运行环境为 Windows、Python、NumPy、PyYAML、Pillow、pywin32 和 FFmpeg。

```powershell
python tests/capture_station_ground.py $zip "$run/side"
python tests/capture_station_ground.py $zip "$run/jump" --airborne
python tests/capture_station_ground.py $zip "$run/watt" --watt
python tests/capture_station_ground.py $zip "$run/original" --original
python tests/review_station_ground.py $oldRun $oldZip $run $zip $report
```
