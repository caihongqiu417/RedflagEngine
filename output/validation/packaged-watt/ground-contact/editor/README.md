# 在 Forge 里调整角色的碰撞体

在层级中点选角色，场景视口就会显示黄色胶囊。它表示物理系统用来判断角色占了多大空间的形状。右侧「3D 胶囊碰撞体」里的中心偏移以模型原点为起点；总长沿着选定的轴，从一个圆头量到另一个圆头。这里用发行包的机器人模型和一块单独的地台，让轮廓在普通编辑视角下也看得清楚。[选中角色](before.png)

按住 Ctrl 点击半径，可以直接输入米数。本次把 0.35 米改为 0.46 米，黄色轮廓变宽，总长仍是 1.84 米。按 Ctrl+S 保存、关闭编辑器，再用新的 Forge 进程打开同一份临时场景，右栏仍显示 0.460 米。正式游戏的角色尺寸保持由货场场景决定。[半径修改后](edited.png) · [重新打开](reopened.png) · [场景实际保存的数值](result.json)

打开场景视口上方的「碰撞体」下拉框，选「全部」还能看到地台的青色外框，当前选中的角色仍是黄色。选「隐藏」即可检查角色材质和轮廓。三张图都来自同一份场景，机器人在播放待机动画。[全部碰撞体](all.png) · [隐藏轮廓](hidden.png)
