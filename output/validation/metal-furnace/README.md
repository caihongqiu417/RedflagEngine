# 粗糙金属的环境反射

把一颗完全反光的白色金属球置于均匀白光中，把入射的线性 RGB 设为 (1, 1, 1)。不管打磨得多粗糙，球面最终都应与白色背景一样亮。下图左半来自修正前的着色器，右半来自修正后的着色器。每半从左至右的粗糙度分别是 0.1、0.4、0.7、1；从上至下是白金属、有色金属、黑色塑料。程序从实际 GPU 输出读回浮点数，再单独转换为 sRGB 保存 PNG。修正后上排四颗球融入白色背景。[Vulkan 实测图](vulkan.png) · [OpenGL 实测图](opengl.png)

以前，两个后端都根据视线与法线夹角、材质粗糙度查一张两通道表。令表的两个值为 A、B。对白金属，E = A+B 表示光在微小表面上只反射一次就离开的份额。最粗糙的球面中央实测只有 0.30814。光还可能落到邻近表面，经过多次反射后离开。按 Turquin 在 Filament 中使用的近似，可将已有镜面颜色乘以 1 + F₀ × (1/E − 1)。F₀ 是从正面照射时，各颜色通道的反射率。在金属度可以连续变化的 Redflag 材质上，我们以金属度缩放新增的那部分。这个做法沿用原有镜面反射的方向分布。[Filament 的能量补偿及其查询表定义](https://google.github.io/filament/main/filament.html) · [数学册第 14 页](../../pdf/Redflag-Rendering-Math.pdf#page=14)

| 线性 RGB 读数 | 修改前 | 修改后 |
| --- | --- | --- |
| 白金属，粗糙度 1，球面中央 | (0.30814, 0.30814, 0.30814) | (1, 1, 1) |
| 有色金属，F₀ 为 (0.95, 0.55, 0.20)，相同位置 | (0.29273, 0.16949, 0.06166) | (0.91714, 0.37880, 0.08934) |
| 同一白炉中的黑色塑料 | 原来的环境高光 | 所有球面像素逐通道完全相同 |

在 RTX 5070 Ti Laptop 上，260 × 195 的离屏图用正交视角观察相同的球面法线。OpenGL 使用正式网格的顶点及片元着色器，Vulkan 运行内置材质反射的计算着色器。对照取自提交 `18a014d` 的实际两个着色器。两边使用同一张经 OpenGL 烘焙、写入 RFIBL 文件的 BRDF 表。白色环境、黑色环境和改前版本均跑过。四种粗糙度的白金属所有可见像素与理想值之差至多为 1.2 × 10⁻⁷，黑色环境的最大输出为零。两后端包括有色材质在内的最大线性通道差为 0.000163。CSV 列出三种材质、四种粗糙度下各取三个观察方向的 216 组 RGB 值。[线性读数](linear.csv) · [全图误差](metrics.json)

RenderDoc 1.47 截到了修正后的 Vulkan 白炉。事件 8 调度 33 × 25 个工作组。回放后逐字节核对了所有 50,700 个像素的 RGBA32F 结果，和运行当时的 GPU 读回一致，帧内没有验证消息。这个测试量的是环境光反射的颜色。直接灯光、SSR 命中后从场景读取的倒影仍执行原来的着色代码。原有环境测试也实际验证了开关环境后绿色物体的倒影、屏外红色物体和自发光灯牌。[实际帧](furnace.rdc) · [事件、颜色缓冲摘要与回放结果](replay.json)

在 Windows 仓库根目录执行 `python tests/check_metal_furnace.py` 即可重新生成两边的图片和读数。需要重新抓帧时，加 `--renderdoc "到 renderdoc.dll 的路径"`；随后执行 `qrenderdoc --python tests/replay_metal_furnace.py` 核对这次的 GPU 输出。生产实现分别在 [OpenGL 网格片元着色器](../../../RedflagForge/assets/shaders/Renderer3D_Mesh.glsl) 和 [Vulkan 环境反射函数](../../../Redflag/src/Redflag/Renderer/ScreenSpace/Shaders/Environment.glsl)。
