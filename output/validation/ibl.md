# OpenGL 环境光的像素检查

在仓库根目录构建 Debug x64 的 Redflag，再运行 `tests/run_ibl_tests.cmd`。第一个进程生成环境图并保存烘焙文件。第二个进程重新创建 OpenGL 上下文，把文件读回、重新导出，核对全部 152,866,056 字节。[测试程序](../../tests/IBLTests.cpp) · [烘焙文件的排列顺序](../../Redflag/src/Redflag/Renderer/IBLArchive.cpp)

| 输入与读回位置 | 改动前 | 改动后 |
|---|---|---|
| 全景接缝，红通道两侧原值为 1 与 0；读负 X 面中央相邻两列 | 1、0 | 0.5、0.5 |
| 同一位置，绿通道两侧原值为 128 与 0 | 50、0 | 64、64 |
| 常量环境色 (2, 1, 0.5)；读漫反射贴图六个面的全部 6,144 个 RGB16F 像素 | (1.994140625, 0.9970703125, 0.49853515625) | (2, 1, 0.5) |

接缝用 4×2 的线性 HDR 图。经度循环取样后，显卡能在最左列和最右列之间插值；保留 HDR 的原始亮度后，128 与 0 的中点能读到 64。纯色用例比较两种各查 15,876 次的积分。新版本在每个经纬格子的中心取样，CPU 以双精度算出的单位输入结果约为 1.0001036。显卡用 RGB16F 保存时，上表的新读数恰好等于测试输入。纯色用例总红色接近 2 的允许误差为 0.002，约为半精度浮点数在 2 处的一档间隔。其他环境图的误差还取决于光源大小和采样方向。

数学册的两条灰度带显示其中一整行的 2,048 个红色分量。上表的两列只是这行正中间的读数。测试另检查五层镜面反射图、烘焙文件不完整时保留当前光照，以及上下文销毁前释放纹理和缓冲。[数学册](../pdf/Redflag-Rendering-Math.pdf)
