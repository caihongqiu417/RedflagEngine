# 瓦力的对话和开口时间

旧版里，玩家介绍自己叫青桐，再问瓦力叫什么。瓦力报出名字后，又说上次见过玩家穿工装。第二轮玩家问自己的名字，瓦力把上一轮的话原样说了一遍。对比两个版本的实机记录，可以读到当时的完整台词。[旧版和新版的逐题记录](first-start.json)

这次用 1920 × 1080 的 Vulkan 发行包在 RTX 5070 Ti Laptop 上跑了两局。两局都加载维修站，使用本机 Qwen3-VL-2B 生成文字，用相同的 Dylan 音色读出来。第一局启动了新的语音服务，第二局复用了同一个进程。按 T 输入，按回车发送，每轮等声音播完再问下一题。最后让玩家横向移动，确认输入已经回到游戏。

| 从发送到听见第一个字 | 旧版 | 新版第一局 | 新版再次进游戏 |
| --- | ---: | ---: | ---: |
| 交换名字 | 62.99 秒 | 33.58 秒 | 1.84 秒 |
| 追问玩家的名字 | 16.34 秒 | 1.63 秒 | 1.64 秒 |
| 谈维修站 | 11.88 秒 | 1.68 秒 | 1.75 秒 |
| 聊考试 | 14.84 秒 | 2.50 秒 | 2.64 秒 |

第一局里，模型用 0.82 秒生成了自我介绍，之后又过了 32.76 秒，声卡才读到第一个有声采样。当时语音程序正在载入模型，服务记录的加载时间为 39.995 秒，其中一部分发生在发问前。第二局再追问姓名，文字生成用了 0.58 秒，语音用了 1.05 秒。表中总时间按未舍入的数据计算。每局每题只有一个样本，回答长度和机器当时的负载都会影响等待时间。[第一局声音记录](first-start-media.jsonl) · [第二局逐题用时](warm.json) · [第二局声音记录](warm-media.jsonl)

两局里瓦力都答「青桐」，谈维修站时提到了观察记录中确实存在的砂石路和旧油桶。四道题各产生一次意图判断和一次答话。检查记录可以核对原问题、送给模型的材料、模型生成的原文及出现字幕的游戏帧。录音文件保存了游戏实际交给声卡的声音。[模型请求和原始答复](model-trace.jsonl) · [追问姓名的实机画面](recall.png) · [听这一句](recall.wav)

复测时用 `tests/check_station_package.py --conversation` 跑发行包。把前后两局的输出目录和一个 JSON 输出路径交给 `tests/review_conversation.py`，就能用同一套计时口径重新生成对照。[游戏验收](../../../tests/check_station_package.py) · [对照脚本](../../../tests/review_conversation.py)
