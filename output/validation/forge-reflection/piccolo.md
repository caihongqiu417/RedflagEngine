# Piccolo 的碰撞属性怎样进入编辑器

在 Piccolo 的胶囊定义里，半径和半高是两个普通的 C++ 浮点成员。类声明带有 `Fields`，所以生成器会选中这些字段。刚体形状用了另一种写法，先声明 `WhiteListFields`，再逐项标出 `META(Enable)`。这样，本地变换可以显示，运行时算出的世界变换可以留在内部。这里读的是 BoomingTech/Piccolo 提交 `f5053707fed4d3f94d270a436fb0d3a8ae54e3e5` 的源码。[胶囊](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/runtime/resource/res_type/data/basic_shape.h) · [刚体属性](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/runtime/resource/res_type/components/rigid_body.h#L19-L49) · [字段筛选条件](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/meta_parser/parser/language_types/field.cpp)

这些标记怎么变成程序能读的数据？构建时，CMake 调用 PiccoloParser。解析源码时，宏会展开为 Clang 能读取的注解；正常编译时，类仍是普通的 C++ 类型。解析器通过 libclang 读声明，并分别生成反射和序列化代码。模板为字段产生取值、赋值和登记函数，启动引擎时再登记各个类型。[宏定义](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/runtime/core/meta/reflection/reflection.h#L13-L37) · [构建入口](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/precompile/precompile.cmake#L41-L58) · [源码解析和生成](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/meta_parser/parser/parser/parser.cpp#L145-L197) · [字段登记模板](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/template/commonReflectionFile.mustache#L34-L80) · [启动时登记](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/runtime/engine.cpp#L19-L25)

打开编辑器后，`EditorUI::createLeafNodeUI` 读取实例的字段列表，按字段类型选控件。遇到浮点数，会用 `FieldAccessor::get` 拿到当前实例里那个数的地址，再交给 Dear ImGui 的 `InputFloat`。数组按实际长度展开，嵌套类型可以递归查看。Redflag 这次借鉴的是由同一份字段定义驱动属性面板的做法。Forge 中的中文单位、改大或改小会怎样，以及关卡作者挑选数值的记录，都按 Redflag 的玩法和数据格式编写。尤其要注意，Forge 胶囊面板填的是两端之间的总长，Piccolo 声明中的成员名是半高。[绘制字段](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/editor/source/editor_ui.cpp#L452-L521) · [浮点控件](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/editor/source/editor_ui.cpp#L158-L174) · [按实例读取字段](https://github.com/BoomingTech/Piccolo/blob/f5053707fed4d3f94d270a436fb0d3a8ae54e3e5/engine/source/runtime/core/meta/reflection/reflection.cpp#L220-L246)

Redflag 从现有的三个物理组件开始。修改面板里半径的单位或帮助文字，入口是组件字段表；修改某一关卡给玩家选定 0.35 米的理由，入口是关卡旁的取值记录。普通 Python 脚本从字段表生成 C++ 描述，Forge 取得当前实体的值，写入时校验组件约束。这样，作者换关卡或调数值时可以直接修改自己的数据。目前这些字段有明确的登记范围，运行时临时添加的 C++ 成员并不会自动出现在面板里。[字段表](../../../Redflag/src/Redflag/Scene/ComponentFields.json) · [生成脚本](../../../scripts/generate_component_fields.py) · [Forge 属性绘制](../../../Redflag/src/Redflag/Scene/Panel/FieldInspector.cpp) · [货场的取值记录](../../../RedflagForge/assets/scenes/Watt-Station.tuning.yaml)
