# 在 Forge 中查看半径的取值依据

在层级选中玩家，展开右侧的「3D 胶囊碰撞体」。鼠标停在「半径（米）」上，就能读到这个数从哪里量、调大后怎样影响通行，以及半径和总长之间的限制。再展开半径下面的「取值记录」，能看到这个角色最初选 0.35 米的依据，也能区分做过的测量与尚未比较的经验系数。[字段说明实拍](radius-help.png) · [取值记录实拍](radius-tuning.png)

本次在临时场景中把玩家的半径从 0.35 改成 0.42 米。黄色轮廓随输入变宽，总长仍为 1.84 米。按 Ctrl+S 保存后退出，再启动新的 Forge 进程打开这份场景，半径显示为 0.420。场景副本引用维修站的机器人模型，沿用该角色的编号和取值说明。[重新打开后的面板](radius-reopened.png) · [保存前后数据](result.json) · [Piccolo 源码阅读](piccolo.md)
