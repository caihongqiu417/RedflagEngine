# 跑过工具箱时的脚步

录制维修站时，玩家经过红色工具箱，左脚连续三帧突然抬高，第 75 帧的靴尖还朝后转了。将同一版本 Operator.glb 的剪辑采到完全相同的时刻，右脚的运动与画面一致，左脚却分别额外升高了 29、42 和 47 厘米。[原画面与逐帧姿势](../packaged-watt/animation/after/)

地形 IK 在腿部动作上再作一次调整，好让鞋子踩到各自脚下的台阶。旧代码从地面上方 38 厘米向下探测。还原第 74 至 76 帧后，三次射线都从箱子里面出发。PhysX 返回的距离为零，命中点就是起点；另一条从上方落下的射线才量到真正的箱顶，高 0.54 米。旧代码把起点当成了踏面，又把假踏面的高度加到了抬起的腿上。

现在忽略从碰撞体内部返回的起点。遇到真正的台阶时，使用鞋跟和前掌的实际位置判断鞋子要抬多高。穿入台面的脚只补上穿入的距离，已抬过台面的脚继续原来的轨迹。膝盖弯曲时，脚掌保持动画里的方向。下坡另看鞋底离原站姿有多高，让支撑脚随地面下降。[求解代码](../../../Redflag/src/Redflag/Gameplay/TraversalRig.cpp) · [模型点位与米制坐标](../../../RedflagForge/assets/game/station/crew/Operator-Soles.md)

原生测试重放旧画面的三组输入，三次修正后的左脚尖都与原片一致。另把一块踏面摆在 0.20 米处，分别检查左、右脚的抬跟时刻。这个姿势里踝骨已经抬起，前掌却还抵在地面上。修正后两只靴子的最低点都在 0.20 米处；本已高出台面 3.5 厘米的一步没有额外抬高。用屈膝姿势检查低 3 厘米的踏面时，踝骨下降了 3 厘米。改用腿几乎已直的待机姿势，同一目标超出腿长，踝骨只伸到腿长允许的位置。[原生输出](terrain-foot-ik.txt)

在仓库根目录运行 `tests/run_scene_tests.cmd --traversal` 可复测。脚底标定留有独立的全网格对照和逐段误差，普通游戏帧每只脚只检查六个接触点。[测试源码](../../../tests/TerrainFootTests.h)
