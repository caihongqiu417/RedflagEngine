# 玻璃展台

在 Forge 的项目面板打开 `assets/scenes/Glass-Studio.redflag`，选择「青色玻璃」或「琥珀玻璃」。材质的 `AlphaMode` 是 `Blend`。调底色的 Alpha 可以看见墙条透过玻璃的多少，调折射率与厚度可以看墙条错开的位置。演示里的厚度 0.42 与 0.47 采用世界单位，特意放大，使薄层近似产生的错位在正常字号的书页上也能辨认。

## 同一机位的两次截帧

两次运行使用 Debug x64 的 RedflagForge，RTX 5070 Ti Laptop GPU 与 RenderDoc 1.47，同一组两盏点光源，直接光、TAA、同一固定相机。两次均在第 12 帧、相同的 TAA 样本位置取图。画面为 1393 × 893 像素。[straight.png](straight.png) 中两片材质的折射率均为 1，[bent.png](bent.png) 中为 1.5。两个模型均为仓库内原创的一米见方平面，只缩放和摆放一次。

选择事件 27 至 97 可检查 15 笔不透明绘制。事件 112、117 各向三张浮点图加上一片玻璃的颜色、表面方向、深度和光学参数。事件 189 输出最终的显示图。每份图的 PNG 直接由显示图的浮点 RGB 四舍五入到 8 位，比较数字用原始显示浮点值计算，左上角为像素原点。书页上的 detail 图裁取全图的 x=715..1204、y=75..339。原始帧的本地位置、哈希、输出与完整事件表见 [capture.json](capture.json)。

在仓库根目录运行 `tests\run_rhi_tests.cmd` 可复查另一组固定几何。192 × 112 像素的离屏用例分别调换提交顺序、在玻璃前放不透明网格、改变折射率。颜色和遮挡用线性浮点结果比较。编辑器截图的显示颜色已经过色调映射，两组数值各自解释对应的输出。
