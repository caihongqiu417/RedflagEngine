# 红墙对白地板的反射光

`Cornell-RSM.png` 的左右图是同一相机、灯光、12 帧累积下，RSM 关闭/开启的引擎输出；中图来自两次线性 HDR 附件之差。中图把正差值乘 4、截到 `[0,1]`，再用 2.2 伽马显示，便于看见间接贡献，不表示最终画面的曝光。没有使用图像生成或降噪。

最终 Cornell 的方向光为 `[-0.6,-0.6,-1]`，RSM 强度为 1。A 点 `(307,651)` 位于红墙附近的白地面，世界坐标约 `(-1.499,-1.961,1.005)`；B 点 `(716,651)` 位于另一侧白地面。坐标原点在图片左上角。最终 A 点的 HDR 开关差值为 `(0.09644,0.02710,0.02710)`，B 为 `(0.06946,0.06836,0.06836)`。同一图中可以看到有颜色的反弹，也能看到采样噪声与接触附近亮点。

## 修复前后的数值

`measurements.csv` 保存原始浮点读回值，包括 RSM 关闭/开启的 HDR、差值和时域累积后的中间纹理。`before-analysis.json`、`after-analysis.json` 还包括接收面区域均值、反射面的 Flux，以及相机深度重建得到的世界坐标。

为隔离算法改动，以下前后对照保持相同相机、灯光、采样半径与强度。三组关闭 RSM 的 HDR 在前后运行中逐字节相同，最大差值为 0。

| 场景与像素 | 固定强度 | 修复前 HDR 间接增量 RGB | 修复后 HDR 间接增量 RGB |
|---|---:|---|---|
| 原 Cornell 绿墙附近 B | 5 | (0.02197, 0.02783, 0.02246) | (0.12549, 0.22314, 0.13477) |
| 斜照红墙的 Cornell A | 5 | (0.07715, 0.03076, 0.03076) | (0.48218, 0.13550, 0.13550) |
| 独立红墙/白地 A，(127,352) | 1 | (0.05371, 0.00098, 0.00098) | (0.15186, 0.00391, 0.00391) |

这里的亮度是引擎线性 HDR 数值，没有光度标定。修复前后 `resolved` 的归一化约定发生了变化，不能把它当成同一物理单位的测量；最终 HDR 差值用于确认画面贡献的变化。最终展示强度 1 与表中固定强度 5 的 Cornell 实验要分开阅读。

原参考图 `before-CornellBox.png` 使用方向 `[0.25,-0.6,-1]`：红墙的 RSM Flux 精确为 0，绿墙 Flux 均值约 `(0.07544,0.28296,0.09430)`。原图左侧没有红色溢出，首先是因为这盏方向光没有照亮红墙；顶部点光没有被当前 RSM 收集。转向红墙后，修复前已经测到红色贡献，因此不能把问题描述为整条 RSM 没有执行。

## 重新测量同一块地面

使用当前 Debug/x64 引擎，在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run_rsm_scene_tests.ps1 tmp/rsm-diagnostics/current
```

需要 Python 的 NumPy 和 PyYAML。脚本生成 8 个固定配置，重新链接 SceneGallery，然后依次导入、保存、重开并渲染；检查浮点附件有限、红墙/绿墙颜色贡献符合输入方向。两面片夹具在 `tests/fixtures/rsm/`，不依赖 Cornell 以外的大模型。原始 float32 文件保留在指定目录：小端、从左上角逐行、每通道 float32；尺寸和通道数记录在对应 YAML。

重画本文对照图需 Matplotlib：

```powershell
python tests/plot_rsm_scenes.py tmp/rsm-diagnostics/baseline tmp/rsm-diagnostics/after output/scenes/rsm
```

这次修复前的原始运行保留在 `tmp/rsm-diagnostics/baseline`，修复后在 `tmp/rsm-diagnostics/after`；大型浮点附件不纳入 Git。CSV、分析 JSON、前后参考图和图示来源说明随项目保存。重新使用当前版本运行不会生成旧算法基线，旧数值也不能靠当前代码“重建”。

当前仍只有一次漫反射近似，没有 VPL 到接收点的可见性测试；UV 圆盘只覆盖局部反射面。独立两面片的远端接收点仍可因超出采样盘而为 0。这里的测试没有证明无遮挡泄漏、完整多次反弹、移动物体的时域拒绝或与路径追踪一致。
