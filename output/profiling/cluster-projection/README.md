# 正交相机下的灯簇

[CheckClusterProjection](../../../tests/ScreenEffectsTests.cpp) 用 96 × 48 个已知表面组成一面墙，墙在相机前方 3 个场景单位处。一盏点光源位于观察空间 (2.6, 0, −2.5)，半径 0.95。CPU 对每个表面用同一漫反射公式算出可见的光斑，再与 GPU 的分簇筛选逐通道对照。将红通道大于 0.0001 计作光斑，用来避开边缘上接近零的小量。

| 相机 | 旧版漏照 / 应照像素 | 修正后 | 最大线性 RGB 误差，旧 → 新 |
| --- | ---: | ---: | ---: |
| 透视 | 0 / 324 | 0 / 324 | 2.68×10⁻⁷ → 2.68×10⁻⁷ |
| 正交 | 288 / 288 | 0 / 288 | 0.586336 → 2.09×10⁻⁷ |

旧版把簇角写成“从眼睛出发的方向 × 深度”。正交相机的射线起点分散在近平面上，右侧格子被错误地缩到了画面中央。修正后，从每个格子的同一屏幕角反投影出两个位置，沿两点之间的直线找簇的前后截面。透视和正交投影使用同一段代码。

`old.txt`、`fixed.txt` 摘自 Debug x64 在 RTX 5070 Ti Laptop GPU 上的实际运行。PNG 来自 GPU 直接光的 RGB，采用相同曝光。两个 .f32 文件按左上角起逐行存储，每个像素四个小端单精度数，RGB 是线性直接光，A 是候选灯数。解算依赖的掩码见 [ClusterCull.comp](../../../Redflag/src/Redflag/Renderer/ScreenSpace/Shaders/ClusterCull.comp)。

从仓库根目录运行 `tests/run_screen_effects.cmd` 会回归 Sponza 和两种投影。新增回归在修正代码之前先复现漏光，再用相同输入检查结果。
