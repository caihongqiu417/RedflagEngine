# 镂空贴图的覆盖面积

铁丝贴图每四列有一列不透明，远看应当遮住约四分之一的背景。Vulkan 的普通 mip 会把这四列的透明度平均成约 0.25。材质按 0.5 裁剪时，这一格会整个消失。还有另一种材质，整张图的透明度都是 0.25。它在任何距离都应该完全透光。两者的平均透明度相同，能挡住的面积却不同。[当前 Vulkan 缩图](../../Redflag/src/Platform/Vulkan/VulkanDrawResources.cpp) · [材质裁剪](../../Redflag/src/Platform/Vulkan/Shaders/Mesh.frag) · [Castaño 对 alpha mip 问题的说明](https://www.ludicon.com/castano/blog/articles/computing-alpha-mipmaps/)

## 从材质生成面积图

`BuildMaskCoverage` 接受已经解码的底色透明度 A 和独立透明图的红通道 R。两张图的行方向一致，宽和高可以不同。若图片是紧密排列的 RGBA8，给 A 传入第一像素地址加 3 和字节间隔 4，给 R 传入第一像素地址和间隔 4。空通道的值为 1。函数在相同 UV 处对两张原图分别做双线性采样，超出一次平铺的 UV 从另一边接着读。将两次读数和材质透明度相乘，大于或等于裁剪阈值的点才算被遮住。阈值、材质透明度、纹理内容或两张图的坐标关系变化后，需要重新计算。当前接口采用相同 UV 和重复平铺。[接口](MaskCoverage.h) · [实现](MaskCoverage.cpp)

面积图的宽和高分别取两张图中较大的值。默认每格分成 8×8 个小格，每个小格测试一点，各行的横坐标与各列的纵坐标略微错开。通过 16 个点就记 16/64。低分辨率各级按照 UV 矩形占原格的面积求平均，再转为单字节。这样 5 列缩为 2 列时，每格都覆盖 2.5 列。若只有最后一列全被挡住，第二格的覆盖为 1/2.5，即 102/255。源码用二维前缀和保存累计点数，取矩形的四个角就能算出区域内的总数。

返回图中的 64/255 表示大约四分之一的面积被挡住。把这个数再拿去和 0.5 比较，会重新丢掉铁丝。近看可继续用原材质裁剪。远处前景与背景的颜色、深度、拾取，应由绘制方式决定如何处理。这里给的是固定 UV 矩形内的面积估计；斜着看物体时，屏幕像素投影到纹理上的形状还会改变。[相关采样原理](https://research.nvidia.com/labs/rtr/publication/pharr2024stochtex/)

## 数值对照

| 输入与材质 | 面积参考 | CPU 面积图的 1×1 结果 |
|---|---:|---:|
| 每四列一根铁丝，裁剪阈值 0.5 | 25% | 64/255 |
| 整张图是 64/255，裁剪阈值 0.5 | 0% | 0/255 |
| 同一铁丝图，裁剪阈值 0.75 | 12.5% | 32/255 |
| 同一铁丝图，裁剪阈值 0.98 | 1% | 2/255 |
| A 为竖向铁丝，R 为横向铁丝，二者在同一 UV 相乘，再按 0.5 裁剪 | 3.83566% | 10/255 |

一根孤立的铁丝在纹素中心的 A 为 1，左右两个纹素中心均为 0。双线性采样在这条横线上退化为直线。阈值是 0.75 时，从中心向两侧各走 0.25 个纹素就到边缘，留下的宽度为 0.5。除以两根铁丝之间的周期 4，便得到 12.5%。把材质透明度调为 0.5 并把阈值调为 0.375，同样会留下这段宽度。

交叉条纹的 A 沿横向升降，R 沿纵向升降。在一根竖线和一根横线的交点附近，用对称的四块区域分别积分。给定横向的 A 值 a，只有 a 大于或等于阈值 c 才有机会留下；这时纵向的 R 需达到 c/a，满足条件的长度是 1−c/a。每个 4×4 周期内的覆盖比例为 (1−c+c ln c)/4。令 c=0.5 得 3.83566%。分别计算两张图通过阈值的面积再相乘会得到 6.25%，会把铁丝交点画大。

8×8 个判定点是这项试验选用的精度。细到落在采样点之间的轮廓仍有误差，R8 最后还会舍入到最接近的 1/255。对非常细的图案可增加每轴采样数，计算量随其平方增加。对于奇数尺寸，粗层按面积分摊被切开的细格，分摊时视细格内部的覆盖比例为均匀。

## 复现

在项目根目录运行 `tests\run_mask_coverage.cmd`。数学测试包括两张不同尺寸的图、两个错开位置的透明通道、恰好等于阈值的材质，以及原图的最后一列。图像测试使用已有的 1024×32 铁丝 PNG，分别从 A 和 R 建图，11 层结果逐字节相同。测试另可用下列命令检查 Sponza 的轮廓。

```powershell
tests\run_mask_coverage.cmd output/validation/fine-mask/mask.png output/validation/fine-mask/opacity.png RedflagForge/assets/models/reference/Sponza/5061699253647017043.png
```

三张 Sponza 原图各选 32 格轮廓，每格覆盖原图的 8×8 个纹素。测试在每格再均匀取 256×256 个位置，独立计算通过比例。下表给出绝对差值，单位为百分点。它描述这些轮廓与这次采样的差异。
